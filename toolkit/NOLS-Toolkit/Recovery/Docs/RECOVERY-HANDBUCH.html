NOLS / IT TOOLKIT

RECOVERY EDITION 1.2 · Offline-Handbuch · Windows PE / Windows RE

Diagnose zuerst. Kein automatisches Reparieren, Formatieren oder Überschreiben von Bootdateien. Wenn Datenverlust droht: Datenträgerzustand klären und möglichst ein Image erstellen.

1. Aus Windows Setup starten

In einer passenden Windows-Setup-Umgebung mit Umschalt + F10 die CMD öffnen (falls verfügbar). Laufwerksbuchstaben ermitteln:

diskpart
list volume
exit

Volumen mit dem Label Ventoy erkennen. Wenn es hier D: ist:

D:\NOLS-Toolkit\START-RECOVERY.cmd

Die Laufwerksbuchstaben von Windows und vom USB-Datenträger können sich von einem normal gestarteten Windows unterscheiden.

3. Zielsystem vor jeder Reparatur ermitteln

Prüfliste: Ist die Windows-Partition sichtbar und entsperrt? Handelt es sich wirklich um die gesuchte Installation? Sind UEFI/GPT beziehungsweise BIOS/MBR korrekt zugeordnet? Ist die EFI-Partition identifiziert? Ist das Laufwerk mechanisch/elektronisch gesund? Gibt es eine aktuelle Sicherung?

4. Spätere Reparaturmodule

Phase A: Gezielte SFC-/DISM-Prüfung mit Offline-Windows- und Bootpfad.
Phase B: Reparatur mit /scannow oder /RestoreHealth erst nach Bestätigung und kompatibler Quelle.
Phase C: CHKDSK mit Reparaturparametern nur nach Backup und SMART-/Hardwarebewertung.
Phase D: Bootloader-Reparatur mit BCDBoot nach Sicherung des BCD und eindeutiger Zuordnung von Windows/EFI/Firmwaremodus.
Achtung: DISM /Online aus WinPE würde die gerade laufende PE-Umgebung ansprechen, nicht automatisch das kaputte Offline-Windows. bcdedit /enum all kann ebenfalls nur die gestartete Umgebung zeigen. Nie ohne Zielprüfung Änderungen durchführen.
