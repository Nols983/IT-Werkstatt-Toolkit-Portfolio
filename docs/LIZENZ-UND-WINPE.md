# Lizenzierung – Stand der Vorbereitung

Die CMD-/VBS-/Python-/PowerShell-Quelltexte wurden vom Projektentwickler
bereitgestellt. Daraus folgt **keine** Übertragung von Microsoft-Rechten.

Die Windows-PE-ISO aus dem Microsoft ADK enthält Microsoft-Binärdateien
(insbesondere `boot.wim`). Der technische Build und die beabsichtigte Nutzung
sind von der **öffentlichen Weiterverteilung einer fertigen ISO** zu unterscheiden.
Eine verbindliche allgemeine Erlaubnis für das GitHub-Hosting dieser ISO wurde
für die konkrete verwendete ADK-Lizenz noch nicht nachgewiesen.

Daher: **Keine ISO öffentlich verteilen, solange die jeweilige Lizenz bzw.
Redistribution-Berechtigung nicht eindeutig geklärt ist.**

Als vorläufiger Weg wird ein lokaler Build aus dem **vom Nutzer selbst bezogenen
Microsoft ADK + WinPE-Add-on** beschrieben. Auch dabei müssen Microsofts
Nutzungsbedingungen eingehalten werden.
